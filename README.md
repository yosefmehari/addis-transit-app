# Addis Transit & Taxi Hub (መገዲ መጓዓዝያ ኣዲስ ኣበባ / የአዲስ አበባ ሙሉ የትራንስፖርት፣ የታክሲና የክልል አውቶቡስ መመሪያ)

A complete, modern, full-ecosystem public transport and taxi web application for Addis Ababa, Ethiopia.

---

## 🌟 Full Transport & Taxi Coverage

### 1. 🔍 Interactive "Find Taxi Place" (የታክሲ ተራ ፈላጊ)
- Simply type or pick any destination in Addis Ababa in **English, Amharic (አማርኛ), or Tigrinya (ትግርኛ)** (*e.g., Bole / ቦሌ, Piazza / ፒያሳ, Mexico / ሜክሲኮ, Saris / ሳሪስ, Mercato / መርካቶ, Jomo / ጆሞ, Kality / ቃሊቲ, Ayat / አያት, Arat Kilo / አራት ኪሎ, Shiro Meda / ሽሮ ሜዳ, Kera / ቄራ*).
- Instantly discovers:
  - **Which Taxi Ranks (ተራዎች)** have minibuses going there.
  - **Exact Street Landmark / Where to Board** (e.g., *Under Mexico Flyover beside Bunna & Shay Building*).
  - **Official Minibus Tariff in ETB** & estimated travel time in minutes.
  - **Conductor / Weyala Shout** with voice speech output (*"ቦሌ ቦሌ! ሜክሲኮ ሳሪስ!"*).
  - **🚶 Show Walking Path**: Draws a direct dashed walking navigation line from your location to that taxi stand.
  - **🗺️ Navigate via Google Maps**: Direct GPS directions link.

### 3. 💰 Interactive Multi-Modal Fare Calculator (የታሪፍ ማስያ)
- Slide or set any trip distance (1 to 30 km).
- Real-time side-by-side comparison:
  - 🚊 **Light Rail (LRT)**: 10.00 ETB (Flat across city)
  - 🚐 **Minibus Taxi**: 7.00 - 20.00 ETB (Regulated city tariff brackets)
  - 🚌 **Anbessa City Bus**: 6.00 - 8.00 ETB (Cheapest commuter option)
  - 🚍 **Sheger Express**: 8.00 - 10.00 ETB (Comfortable express)
  - 📱 **Ride / Feres (ጥሪ ታክሲ)**: Base ~100 ETB + ~26 ETB/km meter
- Instantly highlights the **Cheapest** and **Fastest & Green** options!

### 4. 🗣️ Conductor Voice & Transit Slang Soundboard (የወያላ ድምጽና መዝገበ ቃላት)

### 5. 🚦 Live Traffic & Rush Hour Advisory (የትራፊክ ሁኔታ)
- Real-time peak hour rush warning system based on East Africa Time (UTC+3):
  - 🌅 Morning Rush: 07:00 - 09:30 AM
  - 🌆 Evening Rush: 17:00 - 19:45 PM
- Real bottleneck hotspot alerts (Mexico Flyover, Megenagna Roundabout, Gotera Lancia, Bole Road).
- Smart Corridor Development advice (pedestrian walkways, smart bus stops).

### 6. 📱 Ride-Hailing Apps & Direct Calls (የጥሪ ታክሲዎች)
- **RIDE**: Dial `8294` (Base ~100 ETB + ~28 ETB/km)
- **Feres**: Dial `6090` (Base ~100 ETB + ~25 ETB/km)
- **Yango**: Upfront fixed GPS pricing class
- **ZayRide**: Dial `6303`
- **Airport Yellow Taxis**: Official Bole Airport arrivals desk
- **Blue Lada Contract Taxis**: Traditional private hire (ኮንትራት)
- Direct one-tap click-to-call links.

- **Backend API**: [**http://localhost:5000/**](http://localhost:5000/)

### Database Setup with Supabase
To sync with your live Supabase database:
1. Open `.env` and replace `[YOUR_PASSWORD]` with your actual Supabase database password:
   ```env
   DATABASE_URL=postgres://postgres:yourpassword@db.qfdxipetmxfccalkvorc.supabase.co:5432/postgres
   ```
2. Run the database migration script:
   ```bash
   npm run db:seed
   ```
*(Note: If no database password is provided, the application runs seamlessly using built-in high-speed mock data).*

### Key API Endpoints
- `GET /api/v1/taxi/find-place?to=Bole` — Multilingual taxi rank finder (works with English, Amharic `ቦሌ`, and Tigrinya).
- `GET /api/v1/taxi-teras` — All 15 taxi ranks across Addis Ababa.
- `GET /api/v1/fare-compare?distanceKm=8` — Real-time multi-mode fare comparison.
- `GET /api/v1/slang-dictionary` — Ethiopian transit slang and conductor shouts.
- `GET /api/v1/traffic-advisory` — Rush hour status and bottleneck alerts.
- `GET /api/v1/taxi-services` — Ride-hailing dispatch numbers and pricing.
- `GET /api/v1/regional-terminals` — 4 intercity cross-country bus terminals.
- `GET /api/v1/feeder-bajaj` — Bajaj feeder transport zones and tariffs.
- `GET /api/v1/routes/plan?originId=6&destId=3` — Multi-hop journey planner.
